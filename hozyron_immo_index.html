Jalons

Simulation simplifiée : loyers et charges constants, prêts amortissables à mensualités constantes, première échéance au mois saisi. Pas d'indexation, vacance, fiscalité, différé ni vente. Les prêts à taux zéro sont pris en charge.

Mes données

Sauvegarde locale
Les données sont enregistrées sur ce navigateur lorsque son stockage est disponible.
Un fichier HTML ouvert localement sur iPhone peut ne pas conserver le stockage d'une session à l'autre. Utilise régulièrement « Exporter mon patrimoine ». Le fichier exporté contient tes données en clair : conserve-le dans un endroit sûr. Aucun compte ni synchronisation n'est prévu dans ce prototype.
